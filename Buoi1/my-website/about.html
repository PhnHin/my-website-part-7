Về tôi

Tôi là Phan Trọng Hiển, sinh viên năm 2 ngành Kỹ thuật phần mềm. Tôi đang học tập và rèn luyện kỹ năng để phát triển bản thân trong lĩnh vực công nghệ thông tin.

Trong quá trình học, tôi luôn cố gắng nâng cao khả năng tư duy logic, kỹ năng làm việc nhóm và sự chủ động trong học tập. Tôi mong muốn được tiếp tục khám phá và áp dụng những kiến thức mới vào thực tế.

HTML
Lập trình cấu trúc nội dung của một trang web.
CSS
Thiết kế và định dạng giao diện cho trang web.
Git
Quản lý phiên bản và phối hợp công việc nhóm hiệu quả.

Kỹ năng

  • HTML
  • CSS
  • Git
  • JavaScript cơ bản

Lộ trình học tập

  1. Hoàn thành tốt các bài tập HTML và CSS trong học kỳ này.
  2. Nâng cao kỹ năng Git để làm việc nhóm hiệu quả hơn.
  3. Rèn luyện kỹ năng mềm và duy trì thành tích học tập tốt.
